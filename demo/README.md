# Demo output (hand-written, not Docling)

`demo/docs/` is a small engine-output-shaped folder used by the API, the Q&A tests and the
demo video. It is **not Docling output**. It is generated by `make_demo.py`:

```bat
python demo\make_demo.py
```

| Document | Table verdict | Why it exists |
|---|---|---|
| `sales_2026` | PASS | cell/total/aggregate questions with valid totals |
| `regions_2026` | PASS | month aliases and comparisons |
| `team_roster` | PASS, not verifiable | no Total row/column → warning path |
| `broken_budget` | FAIL | wrong Total (99 instead of 40) → refusal path |
| `scanned_report` | document failure | 0 tables → refusal path |

For real Docling output, run the engine and point the API at `output/`:

```bat
python -m engine.convert samples --out output
set DOCLING_OUTPUT_DIR=output
python -m uvicorn api.main:app --reload --host 127.0.0.1 --port 8000
```

The API exposes `chunking_method` per document, so the demo can state honestly whether
HybridChunker (`hybrid`) or the Markdown fallback (`markdown`) produced the chunks.
